## 74. Decision Guide

اگر فقط داده می‌خوانید:

```
Query

```

اگر Stored Procedure آماده دارید:

```
StoredProcedure

```

اگر Function دیتابیس دارید:

```
Function

```

اگر لیست دستی کوچک دارید:

```
OptionalOptions

```

اگر SQL پیچیده یا Command دارید:

```
EnterpriseEditor

```

اگر داده از Form/Entity داخلی GraphBPMS می‌خواهید:

```
SystemicEntity

```

اگر SOAP/WSDL دارید:

```
WSDL

```

اگر HTTP API دارید:

```
REST

```

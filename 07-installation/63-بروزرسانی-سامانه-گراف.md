# بروزرسانی سامانه گراف

> [!NOTE]
> 🧭 **مسیر در دانشنامه:** `نصب و بروزرسانی سامانه` ❯ `بروزرسانی سامانه گراف`  
> 🔗 **صفحه مادر در دانشنامه:** [https://wiki.graphbpms.ir/modules/install](https://wiki.graphbpms.ir/modules/install) (بخش «بروزرسانی سامانه گراف»)

ابتدا سامانه را از طریق Internet Information Service متوقف می کنیم

![update1.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=8DEC4212-BE12-42E5-BC1F-9A93EC73CA92.png)

توقف سامانه از طریق IIS

پس از دریافت نسخه جدید سامانه باید آن را بر روی سرور و یا سیستم مد نظر خود بارگذاری کنیم و سپس وارد پوشه نسخه قدیمی سامانه بشویم. برای اطمینان از محل پوشه نسخه قدیمی سامانه می توانیم از قسمت explore وارد آن شویم

![update2.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=5C5D5CDB-1534-4F9B-964B-AD1026B52B81.png)

یافتن پوشه نسخه قدیمی از طریق Explore

![update4.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=AA3490B9-DBAC-4E4A-8AD8-B6CEDD5C36DE.png)

مشاهده پوشه نسخه قدیمی

برای بروز کردن سامانه باید پوشه های `bin`، `content`، `Mobile_PWA` و فایل های `notification-sw`، `service-worker` و `Web.Config` را از نسخه جدید جایگزین نسخه قدیمی کرد

> [!WARNING]
> **توجه**
> 
> قبل از جایگزین کردن web.config بهتر است نسخه قدیمی را تغییر نام داد تا اطلاعات connection string را از نسخه قدیمی به نسخه جدید منتقل کنیم

![update3.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=4AE87250-4539-40E2-A2BE-72E834395232.png)

جایگزینی پوشه‌ها و فایل‌های نسخه جدید

![update5.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=06CB6AD0-2F90-44C4-953C-1C318BCDB7C2.png)

نمای پوشه‌های جایگزین‌شده

پس از جایگزین کردن فایل ها باید connection string را از web.config نسخه قدیمی در نسخه جدید کپی کرد

![webconfigimage.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=CD40A8AA-A47B-433D-8D0B-22C124DC9D53.png)

کپی ConnectionString از web.config قدیمی به جدید

**نمونه ConnectionString :**

```
<add name="BPMS" connectionString="Data Source=(localhost);Initial Catalog=bpms; user id=sa;password=123; MultipleActiveResultSets=True;" providerName="System.Data.SqlClient" />
```

> [!NOTE]
> **نکته**
> 
> در نسخه های جدید سامانه باید در ConnectionString عبارت `MultipleActiveResultSets=True` باشد

```
Data Source : آدرس سرور پایگاه داده 
Initial Catalog : نام پایگاه داده
user id : شناسه
password : رمز عبور
```

سپس باید کوئری که در پوشه sql script نسخه جدید می باشد را اجرا کرد

![sqlscriptdirectoryimage.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=9302ABEF-807F-4905-BBEE-E153DADC4226.png)

پوشه SQL Script نسخه جدید

باید دقت داشته باشید که در قسمت message نباید خطایی باشد

![updatescript2.png](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=CD40A8AA-A47B-433D-8D0B-22C124DC9D53.png)

اجرای اسکریپت SQL بدون خطا

> [!WARNING]
> **توجه**
> 
> توجه داشته باشید که باید نسخه سورس پروژه با نسخه اسکریپ یکسان باشد

> [!NOTE]
> **نکته**
> 
> نسخه هر اسکریت در اول کد های آن درج شده و نام فایل اسکریت شامل نسخه اسکریت است

> [!NOTE]
> **نکته**
> 
> اسکریپت های مروبط به سامانه در سورس کد پروژه و در شاخه SQLScript قرار دارد

پس از اجرای کوئری ها می توانید سامانه را start کنید

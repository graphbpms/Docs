# بلاک HTML

بلاک HTML در Form Builder GraphBPMS برای قرار دادن محتوای نمایشی قالب‌بندی‌شده میان فیلدهای فرم استفاده می‌شود؛ برای نمونه می‌توان با آن **متن راهنما**، **تیتر**، **جدول توضیح** یا **هشدار** را در فرم نمایش داد. این بلاک ماهیت محتوایی و نمایشی دارد.

## کاربرد بلاک HTML در فرم

از بلاک HTML زمانی استفاده می‌شود که لازم است محتوای توضیحی یا قالب‌بندی‌شده در میان فیلدهای فرم قرار گیرد. این بلاک برای نمایش محتواست و ماهیت آن با فیلدهای ورود داده متفاوت است.

نمای کلی Form Builder؛ بلاک HTML در گروه «محتوا و نمایش» قرار دارد و پنل «تنظیمات اختصاصی» برای آن باز است.

## جایگاه بلاک HTML در ابزارها

در پنل **ابزارها**، بلاک **HTML** در گروه **محتوا و نمایش** قرار دارد. نام این گزینه در رابط کاربری **بلاک HTML** است.

گزینه «بلاک HTML» در گروه «محتوا و نمایش» پنل ابزارها.

## وارد کردن و نمایش محتوای HTML

بخش **تنظیمات اختصاصی** این بلاک تنها یک ورودی HTML دارد. هر محتوایی که در این ورودی قرار گیرد، در فرم نمایش داده می‌شود. در رابط کاربری، این ورودی به‌صورت یک ویرایشگر قالب‌بندی‌شده همراه با نوار ابزار نمایش داده شده است.

ورودی محتوای بلاک HTML در پنل «تنظیمات اختصاصی».

## نمونه‌های کاربردی

بلاک HTML برای نمایش محتوایی از این جنس در میان فیلدهای فرم کاربرد دارد:

-   متن راهنما
-   تیتر
-   جدول توضیح
-   هشدار

**نتیجه:** بلاک HTML یک Field نمایشی است؛ محتوای واردشده در ورودی HTML را در فرم نمایش می‌دهد و ماهیت آن صرفاً محتوا و نمایش است.

## 4. مراحل مشترک ایجاد Provider

- ورود به «مدیریت منابع داده».

- انتخاب «ایجاد منبع داده جدید».

- انتخاب خانواده منبع: بانک اطلاعاتی یا وب سرویس.

- انتخاب نوع Provider.

- تعیین عنوان.

- انتخاب منبع پایه در صورت نیاز: Database Connection یا WSDL Service.

- تعریف Query / Procedure / Function / REST / Entity.

- تعیین پارامترهای ورودی.

- تست Provider.

- تعیین یا استخراج فیلدهای خروجی.

- تنظیم Paging در صورت نیاز.

- مشاهده Summary.

- ذخیره.

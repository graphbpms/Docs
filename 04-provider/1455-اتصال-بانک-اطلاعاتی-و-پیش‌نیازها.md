فرم ایجاد Connection بانک اطلاعاتی در محیط جاری.

«مدیریت اتصال بانک‌های اطلاعاتی» پیش‌نیاز Providerهای مبتنی بر Database است. اتصال یک‌بار در این ماژول تعریف می‌شود و سپس هنگام ساخت Provider، Report یا سایر بخش‌هایی که به Database Connection نیاز دارند از همان اتصال انتخاب می‌شود.

در صفحه فهرست اتصالات، اطلاعاتی مانند نام/عنوان اتصال، آدرس سرور، نام پایگاه داده، نوع پایگاه داده، تاریخ ثبت، وضعیت «فقط‌خواندنی» و فعال بودن اتصال دیده می‌شود.

### 5.1. فیلدهای ایجاد یا ویرایش اتصال

| فیلد | شرح |
| --- | --- |
| عنوان | نام قابل تشخیص اتصال در بخش‌هایی مانند Provider، Form Builder و Report Designer |
| آدرس سرور | نام Host، IP یا آدرس سروری که Database روی آن قرار دارد |
| نام پایگاه داده | نام Database مقصد |
| شماره پورت | Port ارتباطی مورد استفاده برای اتصال به Database Server |
| نام کاربری | Username مربوط به Database Connection |
| کلمه عبور | Password مربوط به Database Connection |
| نوع پایگاه داده | نوع Engine پایگاه داده |
| تاریخ انقضا | مقدار کنترلی قابل ثبت برای اتصال در UI |
| فعال | فعال/غیرفعال بودن اتصال |
| فقط خواندنی | گزینه موجود در UI برای مشخص کردن اتصال به‌عنوان Read-Only |
| تست ارتباط | کنترل برقراری اتصال قبل از ذخیره |

در UI فعلی گزینه‌های نوع پایگاه داده به شکل زیر دیده می‌شوند:

```text
SqlServer
MySql
OracleSql
PostGreSql
```

تست برقراری ارتباط از داخل این بخش برای SQL Server ارائه شده است.

### 5.2. جایگاه این اتصال در Provider

در زمان ساخت Providerهای بانک‌محور، فیلد «لیست بانک‌های اطلاعاتی» از اتصال‌هایی که در این بخش تعریف شده‌اند پر می‌شود. به این ترتیب Provider به‌جای تکرار Host/Database/User/Password، اتصال از قبل تعریف‌شده را انتخاب می‌کند.

```text
Database Connection
        ↓
Query / StoredProcedure / Function / Advanced Editor
        ↓
Provider
```

### 5.3. نکات اجرایی

-   برای هر محیط Development/Test/Production اتصال‌های همان محیط تعریف شوند.
-   عنوان اتصال باید به‌گونه‌ای باشد که مقصد آن برای طراح قابل تشخیص باشد.
-   Credential واقعی Database در Custom JavaScript، Wiki عمومی یا Screenshot آموزشی قرار نگیرد.
-   تغییر تنظیمات یک اتصال می‌تواند روی تمام Providerهای وابسته به همان Connection اثر بگذارد.

## 90\. اصطلاحات

| اصطلاح | معنی |
| --- | --- |
| Provider | منبع/ارائه‌دهنده داده در GraphBPMS |
| ProviderId | شناسه Provider در استقرار جاری |
| Input Parameter | مقدار ورودی Provider |
| Output Field | ستون/Field خروجی Provider |
| Query | Provider خواندنی مبتنی بر Select |
| StoredProcedure | Provider مبتنی بر Procedure دیتابیس |
| Function | Provider مبتنی بر Function دیتابیس |
| OptionalOptions | Provider داده‌های اختیاری/دستی |
| EnterpriseEditor | ویرایشگر SQL پیشرفته |
| SystemicEntity | Provider مبتنی بر موجودیت داخلی GraphBPMS |
| WSDL | Web Service SOAP/WSDL |
| REST | HTTP API |
| Paging | دریافت صفحه‌ای داده |
| GlobalFilter | فیلتر کلی |
| File Input | ارسال File به Provider |
| File Output | دریافت File از Provider |
| `absoluteMethodHelper` | مجموعه Helperهای سمت Client GraphBPMS |
| `runProvider` | متد اجرای Provider در Custom JS |
| `providerResult` | داده Structured برگشتی در نمونه‌های فعلی |
| `HasError` | وضعیت خطای Result Model |
| `Content-Disposition` | Header مورد استفاده Helper فعلی برای تشخیص Attachment |

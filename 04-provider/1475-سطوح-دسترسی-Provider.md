# سطوح دسترسی Provider

> [!NOTE]
> 🧭 **مسیر در دانشنامه:** `مدیریت منابع داده Provider` ❯ `امنیت، دسترسی و عملیات` ❯ `سطوح دسترسی Provider`  
> 🔗 **لینک نسخه برخط:** [https://wiki.graphbpms.ir/1450/1474/1475](https://wiki.graphbpms.ir/1450/1474/1475)

در این بخش با تعریف و مدیریت سطوح دسترسی ماژول منابع داده یا Provider آشنا می‌شوید. برای هر منبع داده می‌توان دسترسی‌های موردنیاز را به کاربر، نقش یا گروه دسترسی (گروه نقش) اختصاص داد.

-   [مشاهده، ویرایش و حذف دسترسی‌ها](#provider-access-manage)

## ۱. باز کردن تنظیمات سطح دسترسی

در صفحه **مدیریت منابع داده**، هر سطر نمایانگر یک منبع داده یا Provider است. برای تعریف سطح دسترسی، در سطر منبع داده موردنظر روی **آیکون بنفش مدیریت دسترسی** کلیک کنید. محل این آیکون در تصویر زیر با کادر قرمز مشخص شده است.

![صفحه مدیریت منابع داده؛ آیکون بنفش مدیریت دسترسی در سطر اول با کادر قرمز مشخص شده است.](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=4D3FDA21-AF69-46E3-984D-A5168B58B427)

تصویر ۱ — محل آیکون مدیریت دسترسی برای هر Provider.

با کلیک روی این آیکون، پنجره **تنظیمات سطح دسترسی منبع داده** باز می‌شود.

## ۲. انتخاب دریافت‌کننده و تعیین مجوزها

در پنجره تنظیمات، کاربر، نقش یا گروه دسترسی (گروه نقش) موردنظر را انتخاب کنید؛ سپس مجوزهای لازم را مشخص کرده و روی **ثبت دسترسی** کلیک کنید. تصویر زیر فرم تعیین مجوزها را در حالت انتخاب کاربر نشان می‌دهد.

![پنجره تنظیمات سطح دسترسی منبع داده و هشت مجوز قابل انتخاب.](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=1475C51F-A076-4339-A530-2AF4145E0CD0)

تصویر ۲ — انتخاب دریافت‌کننده، تعیین مجوزها و ثبت دسترسی.

مجوزهای موجود در این پنجره عبارت‌اند از:

| مجوز | توضیحات |
| --- | --- |
| ویرایش پروایدر | اجازه ویرایش منبع داده موردنظر. |
| حذف پروایدر | اجازه حذف منبع داده موردنظر. |
| مدیریت سطوح دسترسی | اجازه مدیریت دسترسی‌های تعریف‌شده برای این منبع داده. |
| مدیریت سرویس ساز | اجازه مدیریت بخش سرویس‌ساز مربوط به این منبع داده؛ این بخش برای ساخت سرویس و API از Provider استفاده می‌شود. |
| ایجاد سرویس ساز | اجازه ایجاد سرویس و API بر پایه این منبع داده در بخش سرویس‌ساز. |
| ویرایش سرویس ساز | اجازه ویرایش سرویس‌های ساخته‌شده از این منبع داده در بخش سرویس‌ساز. |
| حذف سرویس ساز | اجازه حذف سرویس‌های ساخته‌شده از این منبع داده در بخش سرویس‌ساز. |
| مجوز استفاده از پرووایدر | با این مجوز، امکان استفاده از Provider موردنظر در سایر ماژول‌ها، شامل **فرم‌ساز، گزارش‌ساز و فرآیندساز**، برای کاربر، نقش یا گروه دسترسی فراهم می‌شود. |

**مجوزهای سرویس‌ساز:** این مجوزها مربوط به ساخت و مدیریت سرویس و API از Provider یا منبع داده هستند.

## ۳. مشاهده، ویرایش و حذف دسترسی‌ها

پس از ثبت، فهرست کاربران، نقش‌ها و گروه‌های دسترسی دارای مجوز در جدول پایین پنجره نمایش داده می‌شود. در این جدول می‌توانید نام و نوع دریافت‌کننده دسترسی را مشاهده کنید.

![فهرست دسترسی‌های ثبت‌شده؛ آیکون مداد سبز برای ویرایش و سطل زباله قرمز برای حذف دسترسی.](https://portal.graphbpms.ir/Archive/GetFileAnonymous?id=3A2DC5FC-7DDF-41CC-A231-BE927C458C0B)

تصویر ۳ — فهرست دریافت‌کنندگان دسترسی و عملیات ویرایش یا حذف.

-   برای **ویرایش دسترسی**، روی آیکون مداد سبز در سطر موردنظر کلیک کنید.
-   برای **حذف دسترسی**، از آیکون سطل زباله قرمز همان سطر استفاده کنید.
